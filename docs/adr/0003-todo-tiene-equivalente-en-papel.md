# Todo lo que hace la web tiene que poder hacerse en papel

El libro vive primero como web, pero de ella salen ediciones impresas (ADR-0002), así que cada mecánica de un caso tiene que tener un equivalente en papel: examinar un punto es «ve a la página X», elegir una opción es «si crees que es B, ve a la página Y», y el lector marca con lápiz lo que ha visto. Lo que solo pueda existir en la web (como recordar qué detalles se han examinado) se admite únicamente como comodidad prescindible: si falta, el caso se tiene que poder jugar y resolver igual.

## Consequences

- Antes de añadir una mecánica a la web, hay que poder describir cómo se jugaría en papel; si no se puede, no entra en el caso.
- La lógica que se ejecuta en el navegador se mantiene mínima y nunca es necesaria para resolver un caso.
